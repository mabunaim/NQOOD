# مصاريك — SPK-001
نسخة التجربة التقنية v0.1 · 2026-10-12

محمود، لا تحتاج إلى كتابة برومبت جديد. هذه حزمة كود قابلة للتشغيل، وليست التطبيق الكامل أو اعتماد UAT.

## الموجود الآن
- واجهة عربية RTL وأرقام إنجليزية، مصروف وإيراد، تصنيفات منفصلة، وصف اختياري.
- حفظ محلي في IndexedDB، إجماليات شهرية دقيقة بثلاث خانات عشرية، وسجل حركات.
- رسالة حفظ ومغادرة / Discard / متابعة التعديل عند وجود تغييرات.
- تشغيل دون إنترنت بعد تجهيز الملفات، وتحديث B1 إلى B2 مع الاحتفاظ بنفس قاعدة البيانات.
- تجربة T08 معزولة لإلغاء عملية كتابة والتحقق من عدم إعلان نجاح كاذب.

## البداية على الآيفون
1. نربط GitHub بحسابك، ثم نحدد المستودع وننشر محتويات dist-b1 على عنوان HTTPS ثابت. لا يوجد رابط منشور بعد.
2. افتح الرابط في Safari بوضع التصفح العادي. أضفه إلى الشاشة الرئيسية من قائمة المشاركة، مع تشغيل خيار فتح كتطبيق ويب إن ظهر.
3. افتحه من الأيقونة. في «فحص التجربة» تأكد أن Build هو B1 وأن جاهزية الملفات تظهر «جاهزة».
4. نفذ SPK-T01–T07 بالتسلسل في docs/TEST_EXECUTION.md، على نفس التثبيت والرابط.
5. نرفع محتويات dist-b2 إلى نفس المسار عند الوصول لاختبار التحديث فقط. من «فحص التجربة» اختر التحقق من تحديث التطبيق، ثم «تحديث الآن».
6. لا تمسح بيانات الموقع ولا تغير الرابط خلال التجربة. تستخدم النسخة بيانات اختبار فقط؛ النسخ الاحتياطي لم يُنفذ بعد.

إنشاء التصنيفات: التعريفات ← مصروفات ← البيت؛ ثم إيرادات ← راتب.
أدخل إيراد 1000 ومصروف 20: المتبقي المتوقع 980.
بعد قطع Wi-Fi والبيانات الخلوية، أضف مصروف 5.125: المتوقع 974.875.

## تجربة T08
من «فحص التجربة» افتح رابط T08. هذه قاعدة بيانات منفصلة وفارغة.
أنشئ تصنيف البيت، ثم اضغط «إلغاء الحفظ التالي — T08» في شاشة الفحص.
أدخل مصروف 20 وحاول الحفظ: يجب أن تظهر رسالة خطأ وتبقى القيم، دون إضافة حركة.
أعد الحفظ دون تفعيل الفشل مرة أخرى: يجب أن تُحفظ حركة واحدة فقط.
الاختبار يلغي transaction بعد نجاح طلب الإضافة وقبل commit؛ لا يملأ مساحة الجهاز ولا يمس قاعدة التجربة الرئيسية.

## التشغيل على Windows للمطور
يلزم Node.js 20 أو أحدث. افتح Terminal في مجلد المشروع:
```sh
npm ci
npm run build
npm test
npm run serve
```
افتح http://localhost:4173 على الكمبيوتر. لا تفتح index.html مباشرة.
localhost على الآيفون يشير إلى الآيفون نفسه؛ اختبار تثبيت PWA على الجهاز يحتاج رابط HTTPS.

اختبارات المتصفح:
```sh
npx playwright install chromium
npm run test:browser
```
يمكن استخدام Chromium مثبت مسبقًا عبر متغير BROWSER_PATH عند الحاجة.
لا تُرفع node_modules إلى GitHub.

## ملفات الحزمة
- src: المصدر؛ عدله ثم نفذ build.
- dist-b1 وdist-b2: ملفات النشر الجاهزة. ارفع محتويات مجلد النسخة، مع الحفاظ على بنية المجلدات، إلى نفس جذر النشر.
- tests: اختبارات المنطق والتخزين والمتصفح.
- docs: نتائج التنفيذ والقرارات والخطوات التالية.
- tools/test-server.mjs: خادم اختبار محلي فقط؛ لا يُنشر.
- fixtures/t08.html داخل كل نسخة: مدخل اختبار الفشل المعزول.

## حدود هذه النسخة
لا توجد حسابات أو مزامنة أو إرسال للحركات لخادم. بيانات كل جهاز/متصفح محلية؛ النسخة لا تضمن بقاءها بعد حذف بيانات الموقع أو إزالة التخزين بواسطة النظام.
لم يُنفذ بعد: تعديل/حذف الحركات، تعطيل/إعادة تفعيل التصنيفات، تقارير الفئات، تصدير/استيراد النسخ الاحتياطية، أو ترحيل schema.
الأيقونة مؤقتة. العربية هي واجهة هذه التجربة؛ لغة وثائق التسليم والشرح لا تعني إضافة واجهة إنجليزية غير معتمدة.
B1 وB2 كلاهما يستخدم schema version 1؛ نجاح التحديث لا يثبت نجاح ترحيل schema مستقبلًا.
